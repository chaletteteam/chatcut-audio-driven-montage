# 音频驱动多片段混剪（通用版）· ChatCut Skill

根据一段录音/配音（mp3、wav、m4a，或用录像方式录的 mp4/mov），从一批**没有命名**的素材（视频、照片）里自动判断并精选与文案匹配的画面，剪成多片段混剪。

适用于：**产品介绍**、**vlog**、**人物故事 / 个人成长**类视频。

## 怎么用

1. 打开 ChatCut，新建一个项目和对话。
2. 把下面这段话整段复制粘贴到对话框里发送：

```
现在帮我用这个skill剪辑视频：https://raw.githubusercontent.com/chaletteteam/chatcut-audio-driven-montage/main/SKILL.md
```

3. AI 会给你一张素材清单，按清单上传：
   1. 所有要用的素材（视频、照片，没有命名也可以）
   2. 主音频（录音或配音；mp3 或录像方式录的 mp4/mov 都可以）
   3. BGM（mp3，可选）
4. 点「上传好了，开始剪辑」，AI 会一路剪到完成，最后再和你确认要不要调整，或直接导出。

## 这个 Skill 会做什么

- 读懂音频；未处理过的原始录音先粗剪（句间停顿 ≤ 0.8 秒），视频格式的录音会先提取并粗剪成 mp3
- 通看全部素材，按文案匹配最应景的画面
- 每个镜头都从整段素材里精选主角最清楚、表情动作和光线最好的片段
- 开头节奏按类型：产品/vlog 前 3–5 秒快切约 8 个素材；人物故事开头每个画面 ≤ 2 秒
- 素材原声关闭，BGM 自动避让人声
- 一行粗黑体白字字幕（≤12 字、阿拉伯数字、无逗号句号）
- 逐镜头自检，收尾用按钮引导修改或导出，不会自动导出成片

完整规则见 [SKILL.md](./SKILL.md)。
